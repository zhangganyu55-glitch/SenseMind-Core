# 交付 8 · 首次整机联调测试计划（H3-05 V1）

> 2026-11-04 ｜ 目标：在**不改软件、不改硬件**的前提下，证明"一台上电可运行、可拆卸、可维护"的原型机成立。
> 原则：**分级放行**——每一级全部通过才进下一级；任一级失败，停在该级并记录。

---

## 1. 范围与不做什么

| 做 | 不做 |
|---|---|
| 上电、供电、屏、I²C 传感器、按键、充电、8h 连续跑 | 不改固件、不改后端、不改外壳、不重新设计电路 |
| 用现有 H3-05 固件 + 现有 Mac 上位机 / BLE 链路 | 不做临床验证、不声称检测能力 |
| 记录每项实测值与失败现象 | 不做批量生产验证 |

---

## 2. 进入条件（Gate 0）

- [ ] 交付 7 检查清单 A/B/C 全部通过；
- [ ] 交付 5 的 P1–P7 电源判据全部通过；
- [ ] 电池极性已用万用表确认（正压、无短路）；
- [ ] 已拍照留档：焊接面、线束走向、合壳前内部。

> 任一未满足，不得开始联调。

## 4. 分级测试

### T0 · 目视与静态（不上电）

| 项 | 方法 | 通过标准 |
|---|---|---|
| T0.1 | 检查 23 根线无破皮、无压痕 | 无 |
| T0.2 | 3V3–GND 电阻 | >100 Ω |
| T0.3 | 电池 B+/B− 不短路 | ∞ |
| T0.4 | 结构无干涉（下盖自然合上） | 不需用力 |

### T1 · 上电与电源（不接电池，仅 USB）

| 项 | 方法 | 通过标准 | 记录 |
|---|---|---|---|
| T1.1 | 插 USB，观察 | 屏亮、无冒烟/异味 | |
| T1.2 | 测 3V3 空载 | 3.25–3.35V | V |
| T1.3 | 接屏+双传感器，测 3V3 | ≥3.15V，无抖动 | V |
| T1.4 | USB 电流表读总输入电流 | 记录；≤500 mA | mA |
| T1.5 | 表面温度（5 min） | <45°C | °C |

### T2 · 显示（SPI）

| 项 | 方法 | 通过标准 |
|---|---|---|
| T2.1 | 观察开机画面 | 无花屏、无全黑 |
| T2.2 | 四页 UI 切换（A 短按/B 短按） | 页面正常刷新 |
| T2.3 | 屏背光均匀性 | 无明显暗角/漏光 |
| T2.4 | 连续刷新 5 min | 不闪、不重启 |

> 若花屏：按 `H3-05-TEST-STATUS.md` 的排查顺序查接线/供电，不改固件。

### T3 · I²C 传感器

| 项 | 方法 | 通过标准 |
|---|---|---|
| T3.1 | 串口 `i2c` 扫描（如固件支持） | 出现 **0x57** 与 **0x68** |
| T3.2 | MAX30102 读 ID | 返回有效 Fifo/Part ID（固件日志 `ppg=1`） |
| T3.3 | MPU6050 读 WHO_AM_I（0x75） | 返回 **0x68** |
| T3.4 | 静止姿态 | 加速度模长 ≈9.7 m/s²，陀螺 ≈0 |
| T3.5 | 遮住光窗/手指按压 | PPG 原始值有可见变化 |

### T4 · 按键

| 项 | 方法 | 通过标准 |
|---|---|---|
| T4.1 | 短按 A / B | 有页面切换 |
| T4.2 | 长按 A / B | 有长按事件（一次） |
| T4.3 | 连续按 20 次 | 无丢键、无双触发 |
| T4.4 | 按键手感 | 不卡、无连击 |

### T5 · 电池与充电

| 项 | 方法 | 通过标准 |
|---|---|---|
| T5.1 | 接电池，插 USB | 系统正常，充电电流 80–120 mA |
| T5.2 | 充电 30 min，测电池电压 | 上升 |
| T5.3 | 拔 USB | 电池供电，系统不断电 |
| T5.4 | 电池供电续航粗测 | ≥3 h（按 57 mA 估算 4.4 h） |
| T5.5 | 充电时壳温 | <45°C |

### T6 · 系统联调（现有软件链路）

| 项 | 方法 | 通过标准 |
|---|---|---|
| T6.1 | 手表 BLE 广播 | 手机/上位机可发现设备 |
| T6.2 | 遥测通知 | 5 s 一次，字段可解析 |
| T6.3 | Mac 上位机 | 能收到数据、事件不报错 |

> 本项只验证"现有软件能跑"，**不修改软件**；如失败，记录到 `docs/` 供软件侧处理。

### T7 · 8 小时连续跑（Soak）

| 项 | 方法 | 通过标准 |
|---|---|---|
| T7.1 | 满电，连续运行 8 h | 不重启、不死机 |
| T7.2 | 每 2 h 记录一次电压/温度 | 温度 <45°C，电压不异常下降 |
| T7.3 | 结束时检查结构 | 无松动、无线材磨损 |
| T7.4 | 拆开检查 | 电池无鼓包、线束无压痕 |

## 5. 失败处理与记录

| 现象 | 可能原因 | 下一步 |
|---|---|---|
| 屏花屏/黑屏 | 屏线接触、3V3 不足、SPI 接线 | 查 T2 记录 + 交付 3 线号 |
| I²C 扫不到 0x57/0x68 | 接线、模块供电、上拉 | 查 T3 记录，测 3V3 与 SDA/SCL 电平 |
| 按键无响应 | 焊点、按键脚位 | 通断复测 |
| 充电电流异常 | 电池、BOOST、充电 IC | 立即断开，按交付 5 排查 |
| 发热 | 短路、稳压过载 | 立即断电 |

**记录格式**：现象 / 测量值 / 可疑点 / 已排除项 / 结论。**禁止"再试一次看看"式反复上电。**
