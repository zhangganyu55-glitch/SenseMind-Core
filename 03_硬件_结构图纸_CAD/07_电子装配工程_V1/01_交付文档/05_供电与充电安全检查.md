# 交付 5 · 供电与充电安全检查

> 2026-11-04 ｜ **核心结论：在 P0.13 拉高、3V3 电流实测通过、电池极性确认之前，禁止接入电池。**

---

## 1. 电源架构（一句话）

```
USB-C 5V ──► 板载充电管理 ──► 3.7V 电池（带保护板）
                    │
                    └──► 3.3V 稳压（受 P0.13 使能）──► 屏 / MAX30102 / MPU6050 / MCU
```

**没有外部充电模块、没有外接升压、没有电源路径切换器件——全部由 ProMicro 板载电路完成。**

---

## 2. 七项检查

### 2.1 电池保护 —— ✅ 双重保护

| 层 | 位置 | 保护内容 |
|---|---|---|
| 第 1 层 | 电池自带保护板 | 过充 4.25–4.3V、过放 2.4–3.0V、过流/短路 |
| 第 2 层 | 板载充电 IC | 恒压 4.2V、充电电流限制、热调节、电池反接保护（视 IC） |

**要求**：电池必须**自带保护板**；裸电芯禁止接入。

### 2.2 充电电路兼容性 —— ✅ 匹配

| 项 | 值 | 判定 |
|---|---|---|
| 电池化学 | 单节 Li-ion / LiPo 3.7V | ✅ |
| 板载充电 | 单节线性充电，默认 100 mA | ✅ 与 250 mAh 匹配（0.4C） |
| 充电截止 | 4.2V | ✅ |
| USB 输入 | 5V / 500 mA | ✅ |

### 2.3 充电电流 —— ✅ 100 mA；⛔ 不要动 BOOST

| 配置 | 电流 | C 率（250 mAh） | 判定 |
|---|---|---|---|
| 默认 | 100 mA | 0.4C | ✅ 安全 |
| BOOST 跳线 | 300 mA | **1.2C** | ⛔ **禁止**（厂家明确要求电池 >500 mAh 才可用） |

**充满时间**：≈3.0 h（100 mA，含 CV 段略长）。

### 2.4 电池正负极 —— ⚠ 接线前必须万用表确认

| 检查 | 方法 | 通过标准 |
|---|---|---|
| 电池极性 | 万用表直流电压档：红笔接电池红线、黑笔接黑线 | 读数 **+3.5 ~ +4.2V**（正数） |
| 板端焊盘 | 对照商品参数图，B+ 在上、B− 在下（以实物丝印为准） | 丝印/焊盘标识一致 |
| 焊后复测 | 焊完 B+/B− 先不装壳，测板端电压 | 与电池电压一致，无短路 |

> **一旦接反，充电 IC 与电池保护板可能同时损坏，且锂电池有起火风险。接反过的电池不得再用。**

### 2.5 3.3V 逻辑电平 —— ✅ 全部 3.3V

| 器件 | 逻辑电平 | 判定 |
|---|---|---|
| nRF52840 | 3.3V | 基准 |
| ST7789V 模块 | 3.3V（VCC 只能 3.3V） | ✅ |
| MAX30102 模块 | 需 3.3V 兼容版（带 LDO/电平转换） | ⚠ 版本待核 |
| GY-521 | 3.3V 或 5V（板载 LDO + 电平转换） | ✅ |

**禁止**：屏 VCC/BL 接 5V；把 5V 逻辑直接送进 nRF52840 GPIO。

### 2.6 传感器供电要求

| 器件 | 供电 | 电流（典型） | 备注 |
|---|---|---|---|
| ST7789V + 背光 | 3.3V | ≈40 mA（背光为主） | 背光经模块限流 |
| MAX30102 | 3.3V | ≈1.2 mA（LED 占空比低） | 峰值随 LED 电流上升 |
| MPU6050 | 3.3V | ≈1.3 mA | GY-521 板载 LDO |
| nRF52840 | 3.3V | ≈15 mA（BLE 连接态平均） | 峰值更高 |
| **合计** | | **≈57 mA 典型 / 70 mA 峰值** | ⚠ **必须实测 ≤ 3V3 输出能力** |

### 2.7 USB 与电池同时供电 —— ✅ 由板载电路自动处理

| 场景 | 行为 | 验证方法 |
|---|---|---|
| 仅电池 | 电池 → 3.3V 稳压 → 系统 | 拔 USB，系统不断电 |
| 仅 USB | USB → 3.3V 稳压 → 系统；电池座空 | 不接电池，屏正常亮 |
| USB + 电池 | 板载充电同时给电池充电 + 供系统 | 插 USB，系统不断电、电池电压缓升 |

**注意**：若系统负载 > USB 输入限流，可能出现 3V3 跌落。**首次插 USB 时同时监测 3V3 与 VBUS。**

---

## 3. 🔴 禁止操作清单（硬性）

1. ⛔ **禁止**从外部向 3V3 / VCC 排针倒灌电源（会与板载稳压冲突）。
2. ⛔ **禁止**在未测 3V3 输出电流能力前接满负载（屏 + 双传感器）。
3. ⛔ **禁止**电池反接、短路 B+/B−、用金属镊子同时碰两个焊盘。
4. ⛔ **禁止**短接/焊接 BOOST 跳线（300 mA 对 250 mAh 电池过流）。
5. ⛔ **禁止**给屏 VCC 或 BL 接 5V。
6. ⛔ **禁止**用可调电源直接给电池充电（必须经板载充电电路）。
7. ⛔ **禁止**在电池鼓包、破皮、发烫时继续使用。
8. ⛔ **禁止**带电插拔电池线（先断 USB，再断电池）。

## 4. 电源安全验收判据

| # | 判据 | 通过标准 | 不通过怎么办 |
|---|---|---|---|
| P1 | 3V3 空载电压 | 3.25–3.35V | 查 P0.13、稳压器 |
| P2 | 3V3 带载电压（屏+双传感器） | ≥3.15V 且不抖动 | 降低背光/换供电方案，先报告 |
| P3 | 3V3 总电流 | ≤ 稳压器能力（实测确认） | 停装，报告 |
| P4 | 电池充电电流 | 80–120 mA | 查充电设置 |
| P5 | 充满截止 | 4.15–4.25V | 停止使用，查保护板 |
| P6 | USB+电池同时 | 系统不掉电、3V3 不跌落 >0.1V | 查输入限流 |
| P7 | 电池极性 | 正压、无短路 | **立即断开** |

> P1–P7 全部通过，才允许进入交付 9 的整机联调。
