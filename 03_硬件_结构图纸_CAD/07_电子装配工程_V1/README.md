# 06 · 电子装配工程 V1

面向"不设计 PCB、不换硬件"的整机装配工程包（8 份文档 + 4 类表格 + 4 张 A2 图纸）。

| 路径 | 内容 |
|---|---|
| `01_交付文档/` | 空间核对、引脚分配、软线方案、连接器、供电安全、装配顺序、上电检查、联调计划 |
| `02_表格/` | 引脚分配 / 网络表 / 线束表（CSV + XLSX） |
| `03_图纸_可编辑DXF/` | 4 张 A2，audit 0 错 0 修 |
| `04_图纸_预览PNG/` | 图纸预览 |
| `05_源文件_可重跑/` | 生成图纸与表格的脚本 |

> **中文字体**：DXF 引用的 `fonts/SenseMindCJK.ttf` 是脚本从本机字体裁出的子集，因字体授权不随仓库分发。第一次打开图纸前请先跑 `python 05_源文件_可重跑/mkfont.py`（macOS 自带 STHeiti）。

## 关键更正（V1.4）

- `01_硬件空间核对报告.md` A4：载板实测为 **0.4 薄面板 + 0.17–0.2 薄边框**（原写"1.6 实心板 / 1.5 让位槽"，与 STEP 不符）
- 新增冲突 **C0-b/C0-c/C0-d**：边框过薄不可打印、传感器必须元件面朝皮肤侧、排针针尾须剪平
- `06_实际装配顺序.md` 4.0/4.1：补针尾剪平与"光窗朝下"判据

## 结论不变

内腔能放下全部模块，但有 5 处硬冲突（C1 屏排针、C2 电池压天线、C3 电池 0.3mm、C4 线束 0.56mm、C5 屏后 2.1mm 通道）。**C2 是设计级 RF 风险，只报告，不改壳。**
