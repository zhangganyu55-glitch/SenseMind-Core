## 2. 怎么改尺寸

```bash
cd 03_硬件_结构图纸_CAD/02_参数化源文件
# 1) 改 watch_v1_params.json 里的数字（单位 mm）
# 2) 重新生成 STEP/STL/CSV（--out . 表示输出到当前目录）
python watch_v1_cad.py --out .
# 3) 重新出图
python watch_v1_docs.py
python watch_v1_preview.py
```

依赖：`pip install build123d trimesh matplotlib pymupdf`

改参数时典型联动（脚本自动算，不用手调）：

- 屏变厚 → 屏仓、主板、电池、下盖整体下移，总厚自动变
- 屏外形变大 → 屏仓报警（超过内腔会打印 WARN）
- 电池变厚 → 电池仓与总厚自动变
- 传感器模块变厚 → 载板位与内底面自动变

**注意**：`case_w` / `case_l` 是外形，改小会挤压内腔；内腔 = 外形 − 2×`wall`。

## 3. 厚度结论（重要）

按交接单的假设值算：

```
表圈 1.0 + 前面板 1.8 + 屏前隙 0.3 + 屏 6.0 + 隙 0.5 + 排针 2.5 + 主板 1.6
     + 隙 0.5 + 电池 4.0 + 泡棉 1.0 + 下盖 2.0  =  21.90 mm
```

- **V1 实际厚度 21.9 mm**，落在交接单预估的 20–24 内，没有压缩任何模块。
- 传感器侧：载板顶 13.0 → 模块底 18.6 → 内底 18.9，与电池侧共用内底面；电池底 18.2，余量 0.7（泡棉压缩吸收）。
- **18 mm 做不到**：仅"主板排针 2.5 + 屏 8-pin 排针（含在 6.0 内约 2.2）"就已经 4.7；去掉后 ≈ 17.2，但必须改 FPC/直接焊线，属 V2 范围。
- **电池只能选 20×30×4（A）**：内腔 12 点区 Y 向只有 21.7，25×30×4.5（B）需要 25，塞不进去；若把 B 抬到传感器之上，厚度会涨到约 27–28 mm。选 B 就得重排布局或改外形。

## 4. 布局决策（与交接单的差异，必须知道）

1. **两个传感器模块转 90° 并排**：15.5/15.56 沿 X、20/20.26 沿 Y，并排占 31.06 ≤ 内腔宽 38。
   - 代价：光学窗中心只能到 **X = −4.56**（不能正好在手表中线），MPU6050 在 X = +11.22 靠 3 点侧。
   - 想居中：内腔要加宽到约 41（外形约 45）或改载板叠层。
2. **电池仓 32×22**（不是交接单的 26×31）：42×46 内腔的 12 点区只有 21.7 深，26×31 放不下。
3. **USB-C 端盖**独立件：壳体上开 13.5×7.5 通孔 + 16.5×10.5×1.2 法兰槽，端盖内嵌 + 外部法兰；改 USB-C 位置只改端盖与 `usbc_z`。
4. **表耳**按 20 mm 表带做，4 个耳位 5×6×3.5，生耳孔 Ø1.6。
5. **表圈是独立装饰环**（1.0 厚），粘/贴在前壳上，不承载。

## 5. 待实测（needs-confirmation / 高风险 assumed）

按优先级：

1. **屏模块**：外形 31.5×33.7、总厚 6.0、8-pin 排针位置与高度、显示区偏移（当前按居中）。
2. **SuperMini**：18×28、USB-C 在哪条短边、天线端位置、排针高 2.5、B+/B− 焊盘。
3. **MAX30102 模块**：厚度 4.0、光窗中心（当前假定在模块中心）、排针方向。
4. **MPU6050**：厚度、孔位。
5. **按钮**：帽径 3.4、本体 6×6、脚距、行程。
6. **电池**：选定 A 型号后的实际长宽厚、出线方向。
