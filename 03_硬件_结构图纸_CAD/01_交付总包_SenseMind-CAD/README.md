## V1.1 相对 V1 改了什么（只动外观，不动装配逻辑）

| 改动 | 数值 | 目的 |
|---|---|---|
| 壳体顶面倒角 | 0.6 mm | 去掉"方盒子"的硬边，出高光线 |
| 表圈缩进 | 比壳体小 0.35（四周 0.175 缝） | 顶面接缝变成一条规整的暗线 |
| 下盖缩进 | 比壳体小 0.35 | 底部也有一条接缝线，不再是平板拼缝 |
| USB-C 端盖法兰 | 16.5×10.5 → **12.5×7.5**，厚度 1.2 → 0.8 | 6 点方向那块"大黑板"缩小，接近平齐 |
| 按键帽 | 边缘 0.5 倒角 + 深色金属材质 | 原来的红圆柱改掉 |
| 配色 | 深空灰壳体 `#3E4248` / 石墨黑表圈 `#0F1013` / 深色金属按键 | 统一深色科技风 |

**V1.2 改动**：只动外观。安装孔位、螺丝柱、屏仓、光学窗位置未变。
所以 V1 打出来的东西和 V1.1 可以互换装配。

## 三个仍然成立的硬约束

1. **总厚 18.80 mm**（V1.3 实测）。仍受 2.54 排针 2.5 mm 限制；要去掉排针换 FPC 才能再往下走。
2. **光学窗中心 X = −4.56**，不在正中（内腔宽度限制）。
3. **电池 25×20×5**，贴在 +Y 半边下盖内侧；传感器占 -Y 半边，两者沿 Y 排开。

## 改尺寸 / 重新生成

1. 打开 `源文件/watch_v1_params.json` 改数字（mm）
2. 双击 `源文件/重新生成.command`
3. STEP / STL / PDF / 预览图 自动刷新

渲染要单独跑（需要 Blender）：
```bash
~/Documents/deepseek-harness/default-workspace/tools/Blender.app/Contents/MacOS/Blender \
  -b --factory-startup -P watch_v1_blender.py -- --shot hero --samples 64 --res 1800x1350 --out hero.png
```

## 渲染的诚实说明

- 几何来自同一套 STL，渲染没有修改任何尺寸。
- 屏幕上的 UI 是**贴图**（取自固件实际界面 `ui_health_live.png`），不是模型里的实体屏幕。
- 没有虚构 PCB 或芯片；爆炸图里只有真实存在的 7 个结构件。
- 材质是 PBR 近似，不代表最终表面处理。
