### 关键手法：兼容别名

4 个页面文件里共 **71 处**引用了旧颜色名（`Teal`/`Cyan`/`Ink`/`CardBg`…）。处理方式是在 Theme.kt 里保留同名变量映射到新 token，并标 `@Deprecated`：

```kotlin
@Deprecated("UI 2.0: 用 Primary", ReplaceWith("Primary")) val Teal = Primary
@Deprecated("UI 2.0: 用 TextPrimary", ReplaceWith("TextPrimary")) val Ink = TextPrimary
// …共 12 个别名
```

效果：**整个 App 立刻从深色霓虹切到浅色暖系**，而页面一行没改。编译器会为每一处旧引用报一条弃用警告，正好当成后续逐页迁移的 TODO 清单。

## 二、设计意图（先回答 skill 的三个问题）

| 问题 | 答案 |
|---|---|
| 谁在用 | 家属，多半在**晚上 10 点以后**、卧室灯光下、刚把老人安顿好，用手机看一眼"今晚有没有事" |
| 要完成什么 | **30 秒内确认"现在没事"**，或者在有事时立刻判断"要不要过去看看" |
| 该是什么感觉 | 安静、不刺眼、像一本放在床头的健康记录本，而不是监护仪屏幕 |

由此得到三条硬约束：**低亮度环境不刺眼**（浅底深字，不用深色发光）、**不制造焦虑**（状态色只出现在细条和圆点上）、**信息密度低**（一屏三块，不堆指标）。

### 拒绝的默认值

| 默认做法 | 改成 | 理由 |
|---|---|---|
| 深色背景 + 荧光强调色（原 UI） | 浅米底 + 墨绿单强调色 | 夜间看手机，深色高对比屏反而刺眼；荧光色是"设备在工作"的暗示，不是"人没事"的暗示 |
| 大数字 + 小标签的指标卡网格 | 状态卡打头，指标降为第二层 | 家属先要知道"有没有事"，不是"心率多少" |
| 红/黄/绿三色徽章满天飞 | 颜色只出现在 3–4dp 色条和 6dp 圆点上，文字一律墨色 | 保证小字对比度，也对色盲友好 |

| **Warning 图形 / 白** | **2.996** | 3.0 | ❌ |

### 关于第 20 项

`Warning #C28A43` 对纯白是 **2.996:1**，差 0.004。这是任务书给定的颜色值，我没有擅自改。

现状下的处置：Warning 只用于**文字已明确说明状态**的位置（"待确认""演示数据"），颜色是辅助不是唯一信息载体，符合 WCAG 1.4.11 的例外条款。

若要求严格达标，建议把 `Warning` 微调到 **`#B57E38`**（白底 3.50 / 浅底 3.12 / 页面底 3.22，全过）。**这一项需要你批准后我才改。**

### 另一处主动调整

`TextTertiary #8A9691` 对白底只有 **3.06:1**，11sp 小字不达标。处理方式不是改色，而是**限定用途**：

- 只用于 ≥19sp 大字号（如缺失值 `—` 的 28sp）
- 只用于非文字元素（圆点、分隔线）
- 所有 11–13sp 小字（单位、时间戳、注释）统一改用 `TextSecondary`（5.60:1）

这条规则已写进 `Theme.kt` 的注释。
