# 知微 SenseMind V1.0 硬件设计

基于现有开发板与传感器模块的原型转接底板工程，包含独立的nRF52840穿戴终端和ESP32床边雷达终端。

## 文件入口

- `outputs/SenseMind_Hardware_V1.eprj2`：嘉立创EDA专业版原生可编辑工程。
- `outputs/SenseMind-硬件原理图设计交接.md`：2026-10-31交接时的环境、资料路径、页面信息和设计约束。
- `outputs/硬件资料交接/`：用户附件、厂家手册、通信协议、历史接入记录和API工具。
- `outputs/SenseMind-已有资料核对与精简缺项.md`：资料核对记录。

## 当前保存范围

2026-11-01建立本地Git仓库，保存当前磁盘上的原生工程、资料和交接成果。工程在交接文件生成后已有更新，交接文件中的进度和散列属于当时快照，不代表当前最新绘图状态。
